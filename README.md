Instawareness was developed in 2018-2019 as part of a research project at Ghent University by [Thibault Fouquaert](https://orcid.org/0000-0001-7526-7904) and offered unique ways to gain insights into hidden ranking algorithm behind your Instagram feed.

If you want to read more about the tool Instawareness itself, or about the scientific findings derived from it, you can read our paper that has been published in the journal Information, Communication & Society at http://dx.doi.org/10.1080/1369118X.2021.1883707.

Since the research project at Ghent University is currently not continued or maintained anymore, our tool has become outdated and needs development to work with the new APIs of Instagram. Therefore, this repository has been archived. We encourage researchers in this field to fork this repository and continue the development of instawareness, as it has been scientifcally proven to effectively increase social media curation algorithm awareness.
